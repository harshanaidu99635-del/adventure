### 🔐 Authentication & User Management

- [x] JWT-based authentication
- [x] Login/Logout functionality
- [x] User profiles with customizable information
- [x] Profile pictures
- [x] Travel statistics (countries/cities visited)

- [x] View count tracking
- [x] Image galleries for destinations
